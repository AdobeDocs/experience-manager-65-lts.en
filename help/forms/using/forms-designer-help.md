# Forms Designer help {#form-designer-help}

AEM Forms Designer is a desktop application for authoring and managing PDF and XFA-based adaptive forms in Adobe Experience Manager Forms. Use the resources below to get started, explore samples, and reference Designer's scripting capabilities for this 6.5 LTS release.

* [Using Designer](https://www.adobe.com/go/learn_aemforms_designer_65_lts) - an overview of the Designer workspace and core authoring concepts.
* [Designer Quick Start Tutorials](https://www.adobe.com/go/learn_aemforms_designer_quick_start_65_lts) - step-by-step tutorials for getting started with Designer.
* [Designer Samples](https://www.adobe.com/go/learn_aemforms_designer_samples_65_lts) - downloadable sample forms you can open and adapt in Designer.
* [Designer Scripting Basics](https://www.adobe.com/go/learn_aemforms_scriptingBasics_65_lts) - an introduction to scripting within Designer forms.
* [Designer Scripting Reference](https://www.adobe.com/go/learn_aemforms_scriptingReference_65_lts) - the full reference for scripting objects and methods in Designer.
* [Designer FormCalc Reference](https://www.adobe.com/go/learn_aemforms_formCalc_65_lts) - the full reference for FormCalc, Designer's built-in calculation language.
